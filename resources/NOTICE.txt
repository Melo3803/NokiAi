ZXing sources are recompiled for CLDC 1.1 / MIDP 2.0 with Java 1.1 class files.
No ZXing source functionality is changed. Unused formats and encoding code
are removed by ProGuard. Original author/copyright headers remain in the
source distribution downloaded by the reproducible build.

Build-time tools (not bundled as implementations): Eclipse ECJ 4.6.1,
ProGuard 6.2.2, MicroEmulator API libraries 2.0.4.

The separate offline QR helper uses qrcode-generator 1.4.4 by Kazuhiko Arase,
under the MIT license included in that HTML file.
